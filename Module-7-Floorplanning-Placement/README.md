# Module — Floorplanning, Library Binding and Placement

## 📌 Overview

This module introduces the physical-design stages that follow RTL synthesis.

The major focus is on floorplanning, power planning, placement, standard-cell libraries and cell characterization.

A good floorplan is essential for achieving acceptable area, timing, power and routing results.

The module explains utilization factor, aspect ratio, pre-placed cells, decoupling capacitors, power distribution and pin placement.

It also covers library binding and optimization of standard-cell placement.

The final part introduces cell characterization, timing thresholds, propagation delay, transition time and congestion-aware placement.

# 🚀 Yosys MUX Synthesis

## 📌 Objective
To convert RTL Verilog code of a MUX into a gate-level netlist using Yosys.

---

## 🛠 Tools Used
- Yosys
- Sky130 Standard Cell Library
- Graphviz
- Ubuntu (VirtualBox)

---

## 📂 Project Files
- tb_good_mux.v → RTL code
- good_mux_netlist.v → Synthesized netlist
- mapped_netlist.v → Gate-level netlist

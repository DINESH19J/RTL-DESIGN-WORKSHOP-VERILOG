# 04 — OpenLANE Directory Structure and Design Preparation

## 📌 Introduction

OpenLANE uses a structured directory system to organize designs, configurations, scripts, logs, reports and results.

Understanding this structure is important for running the flow and debugging problems.

Design preparation is the first important step before running synthesis and physical implementation.

---
